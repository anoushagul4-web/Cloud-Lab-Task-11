# Cloud Computing – Lab Task 11

## Role-Based Access Control (RBAC) Implementation

This repository contains my **Cloud Computing Lab Task 11**, which focuses on implementing and demonstrating **Role-Based Access Control (RBAC)** for a cloud-based environment.

## 📌 Lab Task Overview

The objective of this task was to understand how RBAC can be used to manage access to cloud resources by assigning permissions based on user roles.

The project demonstrates:

- User and role management
- Role-based permissions
- Access control
- Resource authorization
- RBAC policy implementation
- Security monitoring and reporting
- Interactive visualization through a dashboard

## 📂 Files Included

### 1. `Task_11_RBAC_Report.html`

This file contains the complete **RBAC Lab Task Report**, including the implementation details, configuration, results, and documentation of the task.

### 2. `technova_rbac_dashboard.html`

This file contains an interactive **RBAC Dashboard** for visualizing users, roles, permissions, resources, and access-control information.

## 🔐 RBAC Concepts Covered

The task demonstrates the relationship between:

**Users → Roles → Permissions → Resources**

Instead of assigning permissions individually to every user, permissions are assigned to roles. Users are then assigned appropriate roles according to their responsibilities.

### Example

| Role | Access |
|------|--------|
| Admin | Full access |
| Developer | Development resources |
| Tester | Testing resources |
| Viewer | Read-only access |
